# F1-race-simulator-
 F1 Race Strategy Simulator  A Python-based simulation of a Formula 1 race including:  - Tire strategies (Soft, Medium, Hard) - Pit stop logic - Tire degradation - Driver skill impact - Random race variation - Overtake simulation - Fastest lap # Features - Lap-by-lap simulation - Dynamic leaderboard - Realistic race gaps - Fastest lap tracking
